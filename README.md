# Notes App Recreation

An independent Expo and React Native project inspired by the iOS Notes interface. Create and edit notes, search saved notes, and revisit them after closing the app. Notes are stored on the device with AsyncStorage.

[Try the browser demo](https://sebastian-gill-notes-demo.violetgrouse1.chatgpt.site/). The browser demo is a separate implementation of the core flows.

## Run locally

1. Run `npm ci`.
2. Run `npm start` and follow the Expo prompts for a compatible device or emulator.
